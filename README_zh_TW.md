## 理念

> **格物、致知、正心、誠意、修身。**
>
> 以電腦技術作為物質世界立身之本，輔助自身成長。**以人為本，以道馭術、以術衛道。**
>
> 無足鳥系列將會使用AI作為輔助工具，圍繞個體需求開發各種對學習、生活有幫助的產品；實現減少重複勞動、高效生活，節省時間以去追尋更有意義的事情。若有幸，無足鳥系列將會成為你學習、生活、娛樂的夥伴。歡迎使用！
